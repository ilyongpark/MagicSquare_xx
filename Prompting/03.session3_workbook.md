# MagicSquare_xx — 세션 3 워크북

## Mom Test 결과 (입력)

| 항목 | 내용 |
|------|------|
| **페르소나** | 4×4 부분 마방진(빈칸 2개·`0`, 값 `1~16`, 마법합 34)을 손으로/코드로 다루는 **학습자** |
| **진짜 문제 (한 문장)** | 4×4 부분 마방진에서 빈칸 2개를 채운 뒤 행·열·대각선 합을 맞추는 과정에서 **검산 대상(대각선)을 빠뜨리거나** 틀린 원인을 바로 짚지 못해, **무엇이 문제인지 확인하는 데만 20분 가까이 낭비**한다. |
| **Mom Test 증거 3줄** | ① “**지난 주**에 빈칸 2개 넣고 … **대각선 하나를 빼먹어서 20분 날렸다**.” ② “**20분 동안 무엇이 문제인지 확인**하다가 알았어.” ③ “4×4 부분 마방진을 손으로/코드로 다루는 **학습자**” |

## 1) 주제 (한 문장)

**학습자가 빈칸 2개를 채운 4×4 격자에 대해, 행·열·대각선 10선을 빠짐없이 검산하고 틀린 줄을 바로 짚을 수 있는 규칙과 테스트 루프를 만든다.**

*(Mom Test: “대각선 빼먹음” → **10선 누락 방지** / “20분 확인” → **원인 추적 비용 절감**)*

## 2) R-G-I-O

| | 내용 |
|---|------|
| **Role** | 4×4 부분 마방진을 풀다가 “행·열·대각선까지 다 맞나?”를 확인해야 하는 **학습자** |
| **Goal** | 채워 넣은 격자가 **10선(행 4 + 열 4 + 대각선 2) 각각 합 34**인지 **맞음/틀림**을 빠르게 알고, 틀리면 **어느 줄**인지 짚기 |
| **Input** | 4×4 정수 격자 — `0`(빈칸) 또는 `1~16`, **빈칸 2개** 포함 |
| **Output** | **판정 결과** — `True` / `False` + *(선택)* **어느 줄(행/열/대각선)이 34가 아닌지** |

## 3) 성공 기준 3개 (Mom Test 증거 연결)

| # | 성공 기준 | 연결 증거 |
|---|-----------|-----------|
| 1 | **대각선 1개만** 틀린 격자를 넣으면 테스트가 **Fail**로 잡힌다 — 행·열만 맞고 대각선이 틀린 케이스 포함 | ① “**대각선 하나를 빼먹어서**” → 검산 **누락** 방지 |
| 2 | “무엇이 문제인지”를 **손으로 20분 확인**하지 않고, **테스트 1회 실행(수 초)** 으로 같은 판정을 내린다 | ② “**20분 동안 … 확인**” → **판정·원인 추적 비용** |
| 3 | **빈칸 2개(`0`)** 가 남은 부분 격자도 입력으로 받아, 채워진 줄의 합 34 여부를 검사할 수 있다 | ① “**빈칸 2개 넣고**” + ③ **학습자** 맥락 |

## 4) 표면 문제 — 이번 프로젝트에서 **하지 않을 것**

| 하지 않음 | 이유 (Mom Test) |
|-----------|-----------------|
| **Solver — 빈칸 자동 채우기** | “프로그램 만들면 푼다” — 표면 문제 |
| **MissingFinder — 빈칸 위치 탐색** | 증거는 **검산 누락·원인 확인 비용**이지 “빈칸 찾기”가 아님 |
| **GridUI / InputHandler / ResultDisplay** | 세션 3 범위 밖, ECB·UI 과잉 |
| **ECB 전체 구조·`SquareValidator`/`Solver` 이름으로 설계** | 솔루션 언어 혼입 — 이번 세션은 **판정 규칙**만 |
| **힌트·자동 교정·“20분→1분” KPI** | Mom Test는 **과거 불편**에서 출발; 미래 효과 약속 금지 |

**표면 문제 (기록용):**

*“4×4 부분 마방진을 Solver·Validator 프로그램으로 만들면, 빈 칸 2개를 빠르게 채우고 행·열·대각선 합 34를 맞출 수 있다.”*

→ **이번 세션: ‘합 34 판정 + 10선 누락 방지’만.**

## 8계층 — 세션 3에서 만드는 것만

### Rule (규칙)

- 4×4 격자, 값은 `0`(빈칸) 또는 `1~16`
- **마법합 = 34** — **행 4개 + 열 4개 + 대각선 2개 = 10선** 각각 합 34 *(대각선 누락 금지)*
- 완성 격자: 1~16 **중복 없음** (부분 격자: `0`은 합산·검사 정책 명시)
- **실패 조건:** 10선 중 **한 줄이라도** 합 ≠ 34 → **틀림**

### Command (명령)

| 명령 | 설명 |
|------|------|
| `validate(grid)` | 4×4 격자가 **10선** 합 34 조건을 만족하는지 **판정** |
| `sum_line(cells)` | 한 줄(행/열/대각)의 합 계산 *(Command 보조)* |

학습자 질문: *“행·열·대각선까지 다 34 맞아?”* → `validate(grid)` 호출

### (Skill) — 선택

- 4×4 격자에서 `0`과 채워진 칸 구분
- 행·열·**대각선 2개** 인덱스로 줄 추출 *(“대각선 빼먹음” 방지)*
- `False`일 때 **어느 줄**이 34가 아닌지 표시 *(② “무엇이 문제인지 확인” 대응)*

### Test Loop (테스트 루프)

```
RED     → 행·열은 맞고 **대각선 1개만** 틀린 격자 → validate() → False 기대 → 실패
GREEN   → validate() 최소 구현(10선 전부) → 통과
REFACTOR → 합산 중복 정리 (필요 시)
```

| 케이스 | 내용 | 기대 | 증거 |
|--------|------|------|------|
| A | 행·열 OK, **대각선 1개** 합 ≠ 34 | `False` | ① 대각선 **누락·오류** |
| B | 올바른 4×4 완성 마방진 (10선 OK) | `True` | 판정 기준 |
| C | 빈칸 2개(0) **부분** 격자 | 정책에 따른 검사 | ① “빈칸 2개 넣고” |
