## 세션 3 워크북 (최종)

### Mom Test 입력

| 항목 | 내용 |
|------|------|
| **페르소나** | 4×4 부분 마방진(빈칸 2개·`0`, 값 `1~16`, 마법합 34)을 손으로/코드로 다루는 **학습자** |
| **진짜 문제** | 검산 대상(대각선) 누락·원인 미확인 → **20분 확인 낭비** |
| **증거 ①** | “지난 주 … **대각선 하나를 빼먹어서 20분 날렸다**.” |
| **증거 ②** | “**20분 동안 무엇이 문제인지 확인**하다가 알았어.” |
| **증거 ③** | “4×4 부분 마방진을 손으로/코드로 다루는 **학습자**” |

### 주제 (한 문장)

학습자가 빈칸 2개를 채운 4×4 격자에 대해, **10선**을 빠짐없이 검산하고 틀린 줄을 바로 짚을 수 있는 **규칙과 테스트 루프**를 만든다.

### R-G-I-O 요약

| | 내용 |
|---|------|
| Role | 10선 검증이 필요한 **학습자** |
| Goal | **맞음/틀림** + *(선택)* **어느 줄** |
| Input | 4×4 격자, `0` 또는 `1~16`, 빈칸 2개 |
| Output | `True` / `False` |

### 성공 기준 3개

1. **대각선 1개만** 틀린 격자 → Fail (증거 ①)
2. **20분 손 확인** → **테스트 1회(수 초)** (증거 ②)
3. **빈칸 2개** 부분 격자 입력 가능 (증거 ①·③)

### Non-Goals

- Solver, MissingFinder, GridUI, ECB 전체
- “20분→1분” KPI, 힌트·자동 교정

### 8계층 (세션 3)

| 계층 | 산출 |
|------|------|
| Rule | 10선, 합 34, 실패 조건 |
| Command | `validate(grid)`, `sum_line(cells)` |
| (Skill) | 대각선 인덱스, 틀린 줄 표시 |
| Test Loop | RED(대각선 오류) → GREEN → REFACTOR |
